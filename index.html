김치 금 프리미엄 대시보드 💰📈

이 대시보드는 국제 금 시세와 비교한 국내 금 시세의 “김치 프리미엄”을 추적합니다. 데이터는 매일 업데이트됩니다.

Note김치 프리미엄이란?

국내 금 가격이 국제 금 가격(환율 반영)보다 얼마나 비싸거나 싼지를 나타내는 지표입니다. (+) 값이면 국내가 더 비싸고(과열), (-) 값이면 국내가 더 저렴한 상태입니다.

1. 김치 프리미엄 테이블 (최근 30일) 📅

최근 김치 프리미엄 및 금 시세 변동 현황입니다.

Code 
# 테이블 데이터 준비 (최근 30일, 최신순)
table_df = df.tail(30).iloc[::-1][['날짜', '김치프리미엄(%)', '국내금(원/g)', 'International_KRW_g']].copy()
table_df['날짜'] = table_df['날짜'].dt.strftime('%Y-%m-%d')
table_df.columns = ['날짜', '프리미엄 (%)', '국내 금 (원/g)', '국제 금 (원/g)']

# 테이블 표시

2. 김치 프리미엄 (%) 📊

국내 금 가격과 국제 금 가격의 백분율 차이입니다.

Code 
fig1 = go.Figure()
fig1.add_trace(go.Scatter(
    x=df['날짜'], 
    y=df['김치프리미엄(%)'],
    mode='lines',
    name='김치 프리미엄 (%)',
    line=dict(color='red')
))

fig1.update_layout(
    title='김치 프리미엄 (%) 추이',
    xaxis_title='날짜',
    yaxis_title='프리미엄 (%)',
    hovermode='x unified'
)
fig1.show()

3. 국내 vs 국제 금 시세 비교 ⚖️

국내 금 시세(원/g)와 원화로 환산된 국제 금 시세의 비교입니다.

Code 
fig2 = go.Figure()
fig2.add_trace(go.Scatter(
    x=df['날짜'], 
    y=df['국내금(원/g)'], 
    mode='lines', 
    name='국내 금 (원/g)'
))
fig2.add_trace(go.Scatter(
    x=df['날짜'], 
    y=df['International_KRW_g'], 
    mode='lines', 
    name='국제 금 (원/g, 환율 반영)'
))

fig2.update_layout(
    title='국내 vs 국제 금 시세',
    xaxis_title='날짜',
    yaxis_title='가격 (원/g)',
    hovermode='x unified'
)
fig2.show()
